What is the Flowtime technique?

Flowtime is a way of timing your work without a fixed countdown. You start a timer, work on one task, and stop when your attention starts to drift or the task reaches a natural end. Then you rest for a time that depends on how long you worked: a short session earns a short break, a long one a longer break.

It suits work that takes a while to get into, like writing, coding or studying a hard topic, where a 25 minute bell can interrupt you at the worst moment.

Flowtime vs Pomodoro

PomodoroFlowtime
Session lengthFixed, usually 25 minutesAs long as your focus lasts
BreaksFixed, usually 5 minutesLonger after longer work
Best forGetting started, review, tasks you've been putting offDeep work: writing, coding, problem sets
Watch out forThe bell cutting you off mid-thoughtForgetting to stop: notice when you start rereading the same line

You can use both: Pomodoro to get going in the morning, Flowtime once you are in the zone. The timer above switches between them.

How to start

  1. Pick one task and write it down.
  2. Start the timer in FlowTime mode and work.
  3. When your focus fades, press Start break.
  4. Rest for the time shown, then pick the next task.
